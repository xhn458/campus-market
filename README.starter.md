# Campus Market

Campus Market is a student marketplace project for buying and selling items within university communities. Sprint 1 aims to demonstrate account creation, login, and a basic marketplace interface.

This repository contains the first runnable project foundation. Registration, authentication, and marketplace data are still Sprint 1 work.

## Project layout

```text
frontend/       HTML views for pages and reusable UI
backend/        PHP bootstrap, configuration, and database access
database/       MySQL schema and initial reference data
public/         Web entry point plus browser CSS and JavaScript
docs/           Setup, workflow, and Sprint 1 planning
```

## Getting started

1. Read [the setup guide](docs/SETUP.md).
2. Review [the Git workflow](docs/WORKFLOW.md).
3. Review the technology choices in [technical decisions](docs/DECISIONS.md).
4. Pick the next ticket from [the kickoff checklist](docs/SPRINT-1.md).

The foundation can run after PHP and MySQL are installed and configured. It is not yet a complete Sprint 1 demo.
